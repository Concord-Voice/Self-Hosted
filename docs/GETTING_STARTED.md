# Getting started with Concord Voice

Concord Voice provides encrypted voice and messaging.

Self-host distribution is available only through a verified public release. This page does not authorize installation or announce an unreleased version. Releases are published on the [Self-Hosted releases page](https://github.com/Concord-Voice/Self-Hosted/releases). v0.3.0 is published, but it has no supported install procedure until fresh-host acceptance ([#74](https://github.com/Concord-Voice/Self-Hosted/issues/74)) passes, so an install link is unavailable.
